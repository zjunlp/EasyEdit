To reproduce 1:1, run the code from [MIKE](https://github.com/jasonrichdarmawan/MIKE)

We welcome other researchers to extend the work. MIKE's repository consists of the source code for the mechanistic interpretability methods, knowledge editing methods, and analysis to generate the statistics and figures.

MIKE's knowledge editing methods consits of **Revised_AlphaEdit** and **AlphaEdit_Circuit**. However, we only create pull request for Revised_AlphaEdit because **AlphaEdit_Circuit** do not outperform prior studies; **only avoid model collapse suffered by prior studies**. Thus, we welcome other researchers to extend AlphaEdit_Circuit. For example, figure out how to make the covariance matrices from per-layer to cross-layer and contribute to EasyEdit library.

We also welcome researchers to take interest in Mechanistic Interpretability and Knowledge Editing research topics, mainly to analyze how post-edit model use the edited knowledge.

Thank you for interest in these research topics.
